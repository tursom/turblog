# Xeelee Sequence 中文试译术语表

本表用于仓库内的非正式中文试译，目标是让人物、地点、技术名词和计量表达在全系列中保持一致。通过本地 SearXNG 检索后，尚未发现全系列的正式中文版；中文社区及零散正式发表短篇也没有形成完全统一的系列译名。因此，下表优先记录已有中文用法并标明来源层级，不把社区译法表述为权利人认可的正式译名。

## 翻译原则

- 忠实保留原文信息、段落、视角和语气，不删节，不擅自补充解释。
- 人名以音译为主；首次确定后跨册保持一致。
- 虚构文明、设施和专名保留其专名属性，不按普通名词随意改译。
- 科学术语采用中国大陆常用译法；`gravity well` 译为“引力阱”，不译为“重力井”。
- 原文将工作轮班同时用作时间单位时，`shift` 统一译为已有中文概述采用的“轮班”，不擅自换算成年、日或小时。
- `gee` 表示以地球表面重力加速度为单位的加速度；根据句式译为“倍地球重力”或“g”。
- 英文章节保留原 slug，中文章节在对应 slug 后追加 `-zh`，通过 `alternateEditionSlug` 和 `parallelSlug` 双向互链。
- 每章初译后至少检查人名、术语、数字、否定词、段落数量和 Markdown 标记。
