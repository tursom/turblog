# 《抵达之前》主推进任务需求与量级核算

核算日期：2026-09-05

状态：研究工作稿，不是已确认的飞船参数表。用户选择先比较发动机性能，尚未决定脉冲或连续推进。原始研究对照见[聚变推进比较](./before-arrival-fusion-comparison.md)。本文数值来自下面明确列出的理想模型，不是任何论文给出的远渡号设计，也不是实测性能。

## 已确认方向与计算假设

已确认的相关方向：

- 数百年太阳系广泛定居之后出发，航程约三百年。
- 船民两万至五万人，三层同轴同角速度环形居住区，共同转速以每分钟一转为基准。
- 主推进采用氘—氦-3聚变；工作形式未定。
- 广泛船内制造与翻修，少数核心元件依赖库存。
- 不能依赖其他殖民路线必然成功；自身须有抵达与建设方案。

仅用于比较的假设：

| 参数                 | 示例值                  | 注意事项                           |
| -------------------- | ----------------------- | ---------------------------------- |
| 目标距离             | 12光年                  | 未正式选择目标恒星                 |
| 巡航速度             | 0.04c                   | 不是用户已确认的发动机性能         |
| 加速与减速           | 各20年，恒加速度        | 是运动学示例；需要推力随质量调整   |
| 有效排气速度         | 对比0.02c、0.03c、0.04c | 不由选择氘—氦-3自动获得            |
| 推进结束后的剩余质量 | 100万吨，即10^9千克     | 仅作线性缩放单位，不是飞船质量估算 |

取 c = 299792458 m/s，一儒略年为365.25日，标准重力加速度 g0 = 9.80665 m/s^2。使用非相对论运动学和理想火箭方程，适用于这里的初步量级比较；最终设计还需修正引力场、轨道机动、速度方向及其他任务细节。

## 运动学

加速到 v = 0.04c，耗时 t_a = 20年：

- a = v / t_a = 0.0189997 m/s^2，约0.001937g。
- 单段加速距离为 v t_a / 2 = 0.4光年，减速段相同。
- 剩余11.2光年以0.04c巡航，需要280年。
- 总计320年，其中主推进高推力阶段合计40年。

对于相同距离、巡航速度和对称恒加减速模型，总时间为 L/v + t_a，不是 L/v + 2t_a。把单段加速时间从20年改为40年，总航程变为340年，但在相同瞬时质量下，所需推力与理想排气功率减半。

因此，约三百年航程与二十年单段加速不是同一项不可分割的要求。

## 质量比

先按不分级、不抛弃结构、排气速度不变，且出发携带全部加减速推进剂计算：

- 总速度增量近似为 delta-v = 2v = 0.08c。
- R = M_initial / M_final = exp(delta-v / v_e)。
- M_final 包括推进结束后仍保留的船体、人口、工业、发动机、库存及未消耗储备；不是只计算居住舱。
- 可消耗推进剂与能源反应燃料不一定是同一物料，须随具体发动机设计区分。

| 有效排气速度 | 比冲约值  | 初始质量/剩余质量 | 剩余100万吨时的初始质量 |
| ------------ | --------- | ----------------- | ----------------------- |
| 0.02c        | 61.1万秒  | 54.60             | 5460万吨                |
| 0.03c        | 91.7万秒  | 14.39             | 1439万吨                |
| 0.04c        | 122.3万秒 | 7.39              | 739万吨                 |

这些是理想质量预算，不包含额外速度余量、泄漏、无法利用的存量等完整工程项目。分级和抛弃空罐需要另建质量模型。降低加速度但维持同一总速度增量，不会直接改善这个理想质量比。

## 推力与功率

理想定向单速排气满足：

- F = M a = mass_flow * v_e。
- P_jet = 0.5 * mass_flow * v_e^2 = 0.5 * F * v_e。

这里的 P_jet 是与推力和有效排气速度对应的理想定向排气动能功率，不是电功率，也不是聚变总功率。真实排气速度分布、发散、未利用产物和其他损失会改变实际能量收支；该关系是比较用的理想值。

相同瞬时质量、相同加速度和有效排气速度，脉冲与连续方式面对相同的平均推力和理想平均排气功率需求。脉冲形式不能消除平均能量约束，连续形式也不能免除散热。

以剩余质量100万吨、恒加速20年为缩放基准：

| 有效排气速度 | 开始加速时的推力 | 开始加速时理想排气功率 | 开始加速时排气质量流率 |
| ------------ | ---------------- | ---------------------- | ---------------------- |
| 0.02c        | 10.37亿牛顿      | 约3110 TW              | 约173 kg/s             |
| 0.03c        | 2.734亿牛顿      | 约1230 TW              | 约30.4 kg/s            |
| 0.04c        | 1.404亿牛顿      | 约842 TW               | 约11.7 kg/s            |

TW为10^12 W。0.03c示例的1230 TW约为1.23 PW。

表中比较固定的是最终剩余质量，不是初始质量。更高排气速度降低携带的推进剂，从而降低这里的初始推力需求；不能据此推导出在相同初始质量和推力下，提高排气速度会降低排气功率。

若真实剩余质量为表中一半，所有推力、功率和流率也按一半缩放。反过来，如果增加散热器、发动机或屏蔽质量，剩余质量也会上升，必须反馈到整个模型，不能只把新增设备当作免费的附件。

## 散热敏感性

不是所有未转化为定向排气的能量都必然由飞船散热器排出。直接逃逸的辐射、未捕获产物、发动机结构吸热、辅助供能损失等必须逐项分开。

下面仅用热负担敏感性说明尺度：假定需要工程散热系统排出的热量，等于上述0.03c示例初始理想排气功率的0.1%、1%或5%。这些百分比不是已知发动机效率，也不是氘—氦-3的固定物性。

理想辐射面积 A_emit = Q / (epsilon * sigma * T^4)，取 epsilon = 0.9，sigma = 5.670374419e-8 W/(m^2 K^4)，忽略背景温度和遮挡：

| 热负担相对上述P_jet | 需排热量  | 1000 K总有效辐射面积 | 1500 K总有效辐射面积 |
| ------------------- | --------- | -------------------- | -------------------- |
| 0.1%                | 约1.23 TW | 约24.1平方公里       | 约4.76平方公里       |
| 1%                  | 约12.3 TW | 约241平方公里        | 约47.6平方公里       |
| 5%                  | 约61.5 TW | 约1205平方公里       | 约238平方公里        |

这是总有效发射表面积，不是投影面积；不能直接与船体直径比较。两面有效辐射、液滴等结构需要另行解释几何面积。数值不含管路、换热器、泵和承载结构的质量。1500 K只是温度敏感性参数，不代表所有发动机部件或冷却回路都允许在该温度工作；低温设备仍要单独处理热负荷。

## 维护时间尺度

在示例任务中，高推力运行合计40年，并非仅一次短期点火。若只用每秒250次脉冲作为计数示例，40年累计约3.16乘10^11次脉冲。该频率不是远渡号已选参数；需要同时确定发动机数量、单次脉冲能量、工作占空比以及各部件可更换周期。

脉冲系统需要验证燃料单元制备、驱动器、注入对准、重复载荷与磁喷管寿命。连续系统需要验证稳定维持、热流、材料辐照、部件更换和停机重启。两者都不能用一次实验运行时长直接外推几十年累计工作。

长巡航期也不是完全停止维护。再次大规模点火之前，需要在不耗尽制动储备的条件下持续诊断、维护和验证能力；检修、试车与减速方案需要共同制定。

## 决策含义

- 首先比较能否达到需要的有效排气速度，而不是只比较推力是否平滑。
- 论文中的行星际推进器与星际探测器通常追求不同工况，不能直接把一方更低的比冲解释为其整个约束路线的物理上限。
- 现有研究可以作为未来技术的参照，但不能证明一艘数万人飞船已能在这个质量与功率预算中成立。
- 脉冲与连续形式的选择仍待用户决定；航速、加速年限、最终质量、发动机比功率和工程热负担应联合迭代。
- 本次核算不修改已经创建的小说大纲，也不把任何研究建议自动提升为用户确认的设定。
