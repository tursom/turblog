我在继续练习化妆一段时间后，终于学会了独自一个人完美地上妆。虽然还只是老一套，但我一直想着从现在开始还能学到很多。这样的话，就算出去也不显奇怪。

但是，即使这样，我还是没有独自悄悄外出女装的胆量。放学后我去Hayato家，利用他寄放在那里的女装道具变身，和他一起出去。那是平时的老规矩。我的家里只有练习用的化妆道具，没有一件女式衣服，也没有假发和鞋子。

像Hayato那样能独自出去的话，应该会更开心吧。但是我却很享受和Hayato在一起。正因为他和我在一起，我才能这么开心地女装吧。

“那Ken是在找新兼职吗？”

“嗯。因为我只做短期兼职”

“那什么样的好呢？”

“嗯……我还很犹豫。我想着试试开咖啡店，但除此之外好像也有别的选择……”

今天我们在Hayato的房间里。两人都化了妆，像开始外出之前一样悠闲地度过。

Hayato戴着金发，以及蓝色隐形眼镜。穿着水色&amp;白色系的衣服，我简直要被那可爱的氛围迷住了。

“呐，Ken。那个最近的车站不是召唤仪式站对吧。你知道车站前的“Mail Run 酒吧”吗？”

“嗯？不，不知道……”

“是那里的问题啊……”

他带着仿佛高兴、又有些害羞的表情，低下了头。看着我的他带着微笑的表情脸红着。

“要不要一起去那里当个临时工……？

“在咖啡店？嗯，好啊！Hayato，在那里打工吗？”

“那个，嗯。前几天开始在那里打工的。之前虽然也做过，但正因为在那里被个有点跟踪狂的家伙纠缠之后，我就辞职了。不过……我又开始工作了。”

“啊，该不会是在那里女装打工吧？”

“嗯。作为女仆打工的。Ken也一起吧？”

女装打工。多少次在我的梦中浮起。

但是，梦和实际做完全是两码事啊。该怎么办。因为有兴致，还是试试看吧。

“一起做吗？”

看着脸上泛红似在害羞地说话的他，我下定决心了。

“嗯……！我也试着在那里打工！”

“那样啊……！谢谢你！好开心啊，Ken来的话肯定会变得很愉快”

说着这话的他，露出漂亮的笑容，洋溢着男性绝对想不到的美感。

“那个，那个……”

“嗯？”

Hayato在露出苦恼的表情之后，装作什么都没发生……地把目光移向了别处。不久就回到了平时的和蔼表情，所以我并没有追问，只是和他一起度过了时光。

ーーーーーー

姐姐因为出差要暂时不在家。因为在那期间不能来看我，姐姐在休息日邀请我出来玩。

“健君陪我去车站前走走已经很久了。有什么想去的地方吗？”

“咦，那个……那，那个……”

Mail Run 酒吧。Hayato打工的地方。如果我说想去那里的话，姐姐会很高兴地答应。

\*\*\*

那是第一次造访的那个地方。

氛围很安静。奶油色的壁纸，褐色的木桌和椅子。透过玻璃装修的店内看向外面繁忙的街道时，那是另一种能让人心情平静、平抚人心的空间。这个味道是咖啡豆的吗。客人不多也不少，是个能让人放松的地方。

“健君，会喜欢这种地方啊？”

“唔，嗯。想着去类似的店里当个兼职……那个，不是这里……是别的地方……”

我在说什么啊。

和姐姐点完单之后，我环视店内。

没有Hayato的身影。

他是因为化妆和假发而变得与平时截然不同。不像我那样一成不变，每次见到不同的他让我很惊讶。

“怎么了？有什么人要找吗？”

“啊，没什么。那个，姐姐，是吧，你去过这里吗？”

“嗯……几年前只来过一次……是和朋友一起的。一个人不会来吧？”

太好了。如果姐姐经常去的地方的话，我会踌躇不敢申请的。

过了一会儿，饮料端上来了，也没有发现像Hayato的人。今天一定是休息日。因为我本来想偷偷来蒙混过关，所以并没有打听他何时上班。

过了一阵，我和姐姐在店里闲逛了一会儿，随后便离开了这里。真是个不错的地方。姐姐原本说想再一起来，我因为担心她是否能常来这里，所以回复得含糊其辞，她便笑着抚摸了我的脸颊。

我想申请这里的兼职。

抱着这样的念头，就在那天晚上，我联系了Hayato。
