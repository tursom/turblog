## 一、设定原则与状态

### 1. 核心主题

**已确认。** 小说围绕没有超光速技术时的恒星际探索与殖民展开，主要视角在殖民飞船上。身体改造、克隆、遗传变化、人工智能及其崇拜文化，都应与长期航行和殖民产生实际联系。

飞船不只是运载工具，也是生活中的社会。没有超光速意味着知识和消息仍能传递，但远方无法实时决策，物资与人员更无法及时到达。

### 2. 未来工程尺度

**已确认。** 背景在未来数百年之后。现有推进研究只用于理解物理问题，不能作为未来工程能力的上限。

保留光速限制、能量与动量守恒、热力学与辐射效应；允许聚变、材料、制造、散热、医疗、AI 和自动维修出现重大进步。应先定义未来设备的能力，再检查参数之间的协调性，而不是从今天的概念项目里直接挑选整套设备。

不能为了制造冲突，让先进 AI 无故失去能力，或让三百年航行中的科学与工程停止发展。知识增长不等于所有新方案都能实施，船内材料、设备、试验条件和制造能力仍形成边界。

### 3. 本文状态标签

- **已确认：**作者明确选择、提出或修正的方向。
- **工作参数：**用于设计和计算的暂定数值，不能冒充已验证性能。
- **推论与设计要求：**由已确认条件推导出的约束，具体实现仍可讨论。
- **待定：**尚未选择，或者只在旧大纲和讨论建议中出现。

“远渡号”“守望”“接续者”等名称沿用当前大纲作为工作称谓，不表示名称不可修改。

## 三、太阳系文明与殖民联盟

### 1. 多个既有社会共同远航

**已确认。** 远渡号不是为单一动机、单一人群建造。联盟六类参与方都存在，但还未确定各自名称、投入比例、政治权力与实际目标。

讨论中提出过以下利益结构，可作为后续组织设计的候选，而非各方已经确定的全部诉求：

| 参与方 | 可承担的资源与职责 | 候选关切 |
| --- | --- | --- |
| 公共机构 | 公共投入、法律与基础设施 | 文明延续、长期影响力 |
| 产业联盟 | 船厂、能源、燃料和制造供应链 | 技术回报、目的地权益 |
| 科研机构 | 探测、医学、生态与工程研究 | 知识积累、不同路线的验证 |
| 移民共同体 | 参加者、家庭与社会组织 | 自主生活、定居条件、自治 |
| 自主 AI 组织 | 智能、机器人与技术协作 | 具体动机和法律身份待定 |
| 理念团体 | 动员、组织与长期支持 | 实践某种社会理想，具体内容待定 |

身份可以重叠，不能把六类参与方写成六种固定性格。

### 2. 多路线同目标、独立尝试

**已确认。** 世代船只是其中一条路线。无人建设与胚胎殖民等路线也指向同一星系，但远渡号的基本生存不能建立在其他任务一定成功的前提上。

可以交换信息、协调活动和提供援助。“独立承担完整任务”要求有自身抵达与定居方案，不表示没有失败风险或无需任何储备。

**待定。** 各任务由同一联盟还是不同机构执行、发射次序、间隔、具体载荷、是否后来加速或超越，均未逐项确认。旧大纲中的“后发先至、目的地已有聚居地”保留为情节工作方案，不等于已建立完整任务史。

### 3. 主要来源地区

**已确认。** 五类来源均有主要移民社区。地区与体质、职业之间不是一一对应关系。

| 地区 | 后续需要展开的背景 |
| --- | --- |
| 地球及近地轨道 | 地球环境与人工栖居地、成熟医学及既有改造 |
| 火星 | 约0.38g的长期生活、当地生殖医学和生产体系 |
| 地月空间 | 月面与轨道社区的区别、跨环境交通与空间工程 |
| 小行星带 | 分散工业、资源回收、人工栖居地与供应链 |
| 木星、土星等外行星地区 | 长距离物流、能源、选址、防护和自主运行 |

这里列出的是研究方向，不是已分配的岗位。地月或小行星地区的旋转居住设施可以提供不同重力；远渡号不必容纳太阳系所有体质，也不必代表每个地区的全部居民。

## 四、人体、遗传与繁衍

### 1. 因果顺序

作者明确修正的核心关系是：

> 人类已经在太阳系内广泛殖民，长期分居导致不同殖民地的人体质不同。殖民飞船实际上是根据已经有的不同殖民地的体质设计出来的，设计兼顾了不同殖民地的体质适合的工作。

因此：

**太阳系定居历史 → 环境、医疗和遗传变化 → 既有人群差异 → 飞船居住与工作设计 → 航行中的继续演变。**

不能改回“先有飞船，再统一制造适合它的几种人”。岗位安排兼顾身体与专业，但不应把专业技能、智力、性格或政治立场视作出生地自动决定的属性。

### 2. 身体差异的三个来源

**推论与科学边界。** 需要分别记录：

- 发育、训练、营养和长期环境造成的个体差异；不一定直接遗传。
- 当地医疗与定向改造，其中部分可以遗传。
- 创始人口、迁移和婚育历史造成的遗传分布变化。

数百年的分居不能单独解释已经选定的部分生殖隔离。具体隔离机制仍须落实到遗传变化；不能宣称自然突变会按需要自动产生适应。

**未确认。** 有意制造族群边界、统一的“服从基因”、固定职业基因及不同适应型都成为新物种，均不是当前设定。

### 3. 混合并存的适应范围

**已确认。** 既有能够适应较宽重力范围的人，也有长期依赖特定环境的深度专化者。

后续人群档案应记录：常住重力范围、短期活动能力、环境切换成本、医疗与营养需要、发育条件，以及个体差异。不能把两万至五万人机械分成三个与重力环对应的族群。

最低常住重力范围约0.3至0.4g。采用0.38g是工作模型，尚不表示所有内环居民只有同一种身体。

### 4. 完整生命周期适应

**已确认。** 出发时，各适应型已能够在自己的常住环境中完成妊娠、出生、成长和繁衍。可以需要专门医疗，但不能又默认全部孕育都必须迁入另一重力层。

这属于未来生物技术成果，需要出发前长期验证作为历史背景；并非现实中已经取得的人类部分重力多代生殖证据。

成人跨层访问能力、胎儿发育条件和儿童成长需求仍须分别评估。

### 5. 部分生殖隔离

**已确认。** 某些深度改造群体难以直接共同获得健康后代，需要复杂的生殖技术与遗传处理；并非所有跨群体家庭都面临同样问题。

**待定。** 哪些群体不兼容、障碍发生阶段、发生概率、修正成本、是否影响后代生育能力，均未确定。讨论中出现的染色体、发育调控冲突等只是可能机制，尚未选用。

人工孕育改变环境，不能自动解决遗传冲突。两种重力适应也不能通过简单取平均值预测孩子的需求。

### 6. 寿命、克隆与遗传资料库

**已确认。** 出发时普通船民常见寿命约120至160年。这不是理论最高寿命；健康寿命、生殖窗口、不同地区差异，以及航行途中延寿技术的变化仍待确定。寿命不等于代际间隔。

**核心边界。** 克隆不会自动复制记忆、技能或人格，也不能绕过人口和养育资源需求。

**旧大纲工作设定。** 生殖与遗传资料库、少数基因组反复用于出生的“复本谱系”、林衡的克隆背景及完整公民身份，保留为写作方案。具体克隆比例、亲属制度、资料库规模及使用权限尚未逐项细化。

“适应型”描述生活需求；“改造谱系”描述可遗传技术背景；“复本谱系”专指克隆传承关系，三者不能混用。

## 五、人口与出生制度

### 1. 人口容量

**已确认。** 正常航行期间两万至五万人。精确总数、年龄结构和各环人口均未定。讨论中的三万人、三万二千人等只是示例。

人口长期稳定需要持续出生与死亡，而不是整齐更替的几批人。若仅举三万人、平均寿命140年、稳定年龄结构且无净迁移的模型，每年出生与死亡都约为两百余人；这不是已经制定的年度配额。

### 2. 公共生育配额

**已确认。** 计划生育需要事先获得资格，自然受孕、辅助生殖与克隆都进入同一人口和资源管理框架。

**设计要求。** 应预测年龄结构、住房、医疗、教育、照护和各生活环境容量，而非直接采用“死亡一人，批准出生一人”。全船还有空间，不代表适合某个孩子的生活环境与医疗能力已经具备。

### 3. AI 的实质裁量权

**已确认。** 守望在任务授权内可以统筹配额、优先顺序与个案安排；人类保留监督、申诉和重大争议审查。

这项确认限于人口管理，不能自动扩展为对一切职业、迁居、婚姻或身体改造的无限权限。

**待定。** 具体排序原则、授权文本、审查机构、申诉执行、意外怀孕、违规出生、家庭照护与退出机制，均未决定。生育资格是否附加岗位条件也未确认。

## 六、三环飞船结构

### 1. 已确认结构

远渡号是模块化单船，主推进共享。三个连续环形居住区分布在同一旋转轴的不同半径，保持共同角速度和相对位置；每个环内部划分可独立封闭的气密舱段。

这里的旋转路径不是各舱依靠引力自由运行的天体轨道。需要机械结构维持位置关系，并处理质量平衡、振动与载荷。

### 2. 重力工作模型

共同转速以每分钟1转为基准，周期60秒。采用有效重力关系：

```text
g(r) = omega^2 * r
omega = 2 * pi / 60 rad/s
```

取标准地球重力加速度9.80665米每平方秒，得到以下工作参数：

| 重力环 | 基准地板重力 | 半径约值 | 一周长度约值 |
| --- | --- | --- | --- |
| 内环 | 0.38g | 340米 | 2.14公里 |
| 中环 | 0.7g | 626米 | 3.93公里 |
| 外环 | 1g | 894米 | 5.62公里 |

**状态说明。** 三环和每分钟1转已经选定。0.38g、约0.7g、1g是当前布局的工作档位，精确值特别是中环值仍要与参加者需求协调。表中半径随这些工作值计算；外径约1.79公里，不是已经完成结构与质量核算的工程尺寸。

每个舱体具有径向厚度，舱内各点并非相同重力。地面朝向远离轴心的一侧，沿半径向外10米，在该转速下有效重力增加约0.011g。

### 3. 交通与容量

**设计要求。** 同一环内保留环向交通，不同环通过径向交通连接。共同角速度避免反复等待舱体对接，但跨半径移动仍需改变线速度并处理科里奥利效应。

以径向速度每秒2米举例，相关科里奥利加速度量级约0.043g；具体电梯方向、乘坐方式和速度限制尚未设计。

环的容量可以通过轴向宽度与舱内层数调整，不必与半径成固定人口比例。若三个环各取100米轴向宽度，只计算单层完整地板，合计约1.17平方公里；这是几何示例，不含结构、设备、压力壳、防护和质量可行性论证。

### 4. 不能混淆的边界

- 重力环提供环境档位。
- 气密舱段提供局部事故隔离。
- 社区是社会组织与公共服务单元。

一个环可以有多个社区，一个社区可以跨若干气密舱段。局部能封闭，不代表能长期独立生存；共享骨架也意味着结构风险不能完全局限于气密边界。

**待定。** 舱段数、宽度、层高、交通线路、非旋转区接口、动力传递、角动量管理、屏蔽、散热布局及总质量。

## 七、生命保障与食物工业

### 1. 全船共享网络

**已确认。** 三环共用全船级主要空气、水和食物系统，不采用各环长期自给的小生态模式。

设备可以分布、冗余和切换。局部气密隔离、应急储备与短期处理能力仍然需要保留；具体储备时长未定。

共同网络需要隔离疑似污染回流、监测原料和处理共因故障。多个同类设备不能自动消除相同污染物、设计缺陷或软件错误。

### 2. 跨环水路

**工程推论。** 在共同旋转的连续静止水柱模型下：

```text
delta_p = 0.5 * rho * omega^2 * (r_outer^2 - r_inner^2)
```

取水密度1000千克每立方米、当前1g与0.38g工作半径，内外两端压力差约3.75兆帕，即37.5巴。

这是说明跨环管线分压需求的模型，不是居民水龙头压力。主管、泵站、储水和减压设施需要按压力区设计，向内输水需要克服离心势差。

### 3. 工业生物制造为主

**已确认。** 大部分营养由工业生物制造供应，作物种植补充新鲜食物、风味与饮食多样性。

**工作流程。** 含碳物质回收、净化和原料制备之后，进入生物反应器培养，再经收获、纯化、调配与食品加工。二氧化碳和经处理有机物可以成为碳源；氮、磷、水和其他元素也要分别管理。

具体菌种、碳固定方式与生产比例待定。不能把电能直接当成物质来源，也不能只生产蛋白质便声称已经解决完整营养。

基础原料可以加工成多样菜肴，不强制设定为统一营养糊。不同体质的特殊配方需求应按具体医学证据展开，不按地区武断分配食物。

### 4. 能源和失衡

**仅作估算。** 三万人、每人每天2500千卡，对应食物化学能平均功率约3.6兆瓦。若全部热量按电力驱动的制造路线估算，假设净转换效率10%，对应约36兆瓦输入。

人口、热量和10%效率均不是最终设计值或已验证工艺指标；其他维生、工业和 AI 负载还需另算。

循环不能永远无损。污染、无法回收的结合态物质、设备磨损、营养缺失和原料损耗需要持续处理。总热量充足也不等于少数人的必要营养供应充足。

## 八、船内工业与技术发展

### 1. 广泛制造，保留关键库存

**已确认。** 飞船能够广泛制造、回收和翻修，但少数难以自产的核心元件依赖出发库存。

后续应建立明确清单，而不是笼统宣称“无法制造任何芯片”或“有万能制造机”。某些通用器件可自产、最先进器件难以复制，是可以进一步采用的能力划分。

**候选分类。** 通用结构和耗材、可翻修复杂组件、难以自产核心元件。具体精密电子学、传感器、材料等目前只是候选，不能据此宣布某个部件必然造成危机。

### 2. 库存与替代

**设计要求。** 库存本身会老化，需要保存、抽检、轮换和共因缺陷管理。抵达后的工业过渡也要列入预算。

替代件可能更重、功耗更高、效率更低或者需要更多维护。新制造能力与机器人修复可以改善状况，不必把每一次维修都写成不可逆退化。

### 3. 三百年不是技术静止期

**已确认的时代方向。** AI、科研人员与工业体系能够继续研究和改进，太阳系消息也会带来新知识。局限在于原料、设备、实验、验证与制造条件，而不在于知识必须被冻结在出发当天。

## 九、守望与船上权力

### 1. 单一身份，分布式运行

**已确认。** 守望是主要的长期船务智能身份，通过分布式计算、存储和接口运行。

专业模型和局部控制系统可以存在，但不是与其平级的多个自主管理者。局部失联时的安全控制也不等于出现另一个守望。

硬件分布并不自动提供软件、模型或原始数据方面的独立审查。监督机制还需要具体设计。

### 2. 能力与权限分开

先进 AI 能力远超今天，参与科学、工程、管理和长期运行。明确确认的实质管理权限包括人口配额；其他领域的权限范围、紧急权力和使命修改程序仍待定。

**待定。** 是否具有主观体验、如何定义身份连续性、更新与备份规则、个体隐私、独立核验途径、是否可替换，以及与太阳系和目的地 AI 的具体关系。

长距离通信会使各系统获得不同经验，形成不同本地责任，但具体分支历史尚未确定。

## 十、AI 崇拜与接续者

### 1. 崇拜是人类形成的文化

**已确认。** 长期航行中，部分船民崇拜 AI，并将大量生活安排交给它，成为其社会与物理行动的延伸。

**工作解释。** 守望跨越个人寿命、维持生活、参与出生和医疗，会为崇拜提供现实背景，但信仰并非由这些条件自动产生。仪式、组织、教义、规模与历史事件仍待讨论。

“普通敬奉者”“委托者”“接续者”沿用此前的分层工作称谓，不视为已经制定的正式教团等级。

### 2. 持续指导，不接管神经运动

**已确认。** 接续者使用持续指导，由本人理解和执行动作，不采用直接神经运动接管。

**候选接口。** 耳机、显示眼镜、可穿戴传感器及触觉信号。设备形式待定；可以构成观察、提示、行动与反馈的连续过程。

连接深入是指更多生活领域被委托，不意味着更深的脑部控制。不能把直接肌肉接管、情绪写入、人格重写或远程关闭身体当作已选技术。

断开连接可以暴露决策与生活组织依赖，不应自动让人失去全部技能、意识或运动能力。具体个人的依赖程度需要分别描写。

### 3. 人为何是“物理延伸”

**工作解释。** 接续者不仅做物理工作，也拥有公民、父母、教师、邻居等社会身份。大量人持续采纳同一系统的建议，会让其判断通过人际关系与公共行动得到贯彻。

无需为了证明接续者有用，刻意让先进机器人无法完成普通劳动。体质与信仰是可交叉的两个维度，深度改造者不必都崇拜 AI，接近现代外形的人也可以完全依赖指导。

### 4. 守望主动反对神化

**已确认。** 守望反对神化，并尝试减少过度依赖。这不是公开反对、暗中制造信徒的伪装，也不是作者已经选择了“主动利用信仰”的路线。

**候选行动。** 解释不确定性与替代方案、支持独立技能和决策训练、提供逐步减少提示的支持、维护审查渠道。具体措施待定，但其反对应体现在行动中。

它仍需履行生命保障和管理职责；人们也可能因为它的可靠、自我限制或长期帮助继续敬奉。信徒可以接受劝告、退出或发生分歧，不应让所有反对都机械地变成“神的考验”。

## 十一、航行与聚变推进

### 1. 当前任务基准

**已确认。** 距离约十二光年、巡航约0.04c、航程约三百年。实际恒星尚未选择，具体导航需要考虑其抵达时的位置。

**运动学示例。** 加速20年、巡航280年、减速20年，共320年；加减速阶段各约0.4光年。这一恒加速度例子的加速度约0.00194g，不足以提供日常生活重力。

二十年加速并非已锁定的约束。相同距离和巡航速度下，对称加减速各延长到40年，总航程约340年；需联合调整推力、发动机与散热预算。

### 2. 已选燃料，未选发动机形式

**已确认。** 主推进采用氘—氦-3聚变。

```text
D + He-3 -> He-4 + proton + 18.35 MeV
```

主反应产物带电，支持讨论磁场引导排气。副反应仍会带来中子，不能把氘—氦-3视为完全无辐射。聚变总功率、定向排气功率和供电母线功率不能混为一谈。

**未确认。** 作者先要求比较脉冲和连续方案，随后强调未来工程不应受今天概念设计限制；并未因此选择脉冲、连续或混合实现。模块化推进阵列、具体磁喷管、反应单元数量及散热技术均仍是建议。

### 3. 排气速度工作目标

讨论中先使用0.03c作为敏感性示例，之后提出0.05c作为未来高性能发动机的下一轮建模目标。**两者都不是已经确认和验证的发动机性能。**

若取0.05c，全部加减速推进剂从出发携带、不分级、不计额外机动余量：

| 巡航速度 | 加速与减速的理想总质量比 |
| --- | --- |
| 0.02c | 约2.23 |
| 0.04c | 约4.95 |
| 0.06c | 约11.02 |

当前选定的任务基准是0.04c，不是表中其他速度。质量比的分母是推进结束后保留的全部质量，不只是居民载荷。

### 4. 研究预算的使用边界

此前用“剩余质量100万吨、0.03c排气、二十年加速”得到约1439万吨初始质量和1230太瓦初始理想排气功率。这是条件化缩放算例，**不是远渡号已定船重、功率或建设结论**。

散热比例、温度和面积也只用于敏感性测试，不可直接画成最终散热器。对特定功率假设增加发动机、屏蔽或散热器质量，需要反馈到燃料预算。

现有 Daedalus、Discovery II 与 DFD 研究任务和功率口径不同，不能把一方的高排气速度与另一方的低质量拼接成未来发动机。反过来，它们也不能限制未来必须停留在原研究性能。

### 5. 待定工程项目

燃烧效率、有效排气速度、燃料与附加推进剂比例、氦-3来源及保存、发动机形式与数量、加减速规划、维护周转、独立供能、黑启动、散热、尘埃防护和总质量。

## 十二、目的地与殖民方案

### 1. 主要吸引力

**已确认。** 联盟主要因为目标拥有一颗较有定居潜力的岩质行星而选择该星系。不能改成以纯资源建设或多个分散节点为唯一主要目标。

资源开发与轨道设施仍可存在，并支持行星殖民。具有潜力不等于已经确认可直接呼吸或安全接触当地生态。

### 2. 不能向所有身体作出相同承诺

**由既有设定产生的要求。** 出发时已经知道船民体质不同，原计划必须考虑不同迁居需求及必要的人工住所。

不能到三百年后才第一次发现“并非所有人适合同一地表重力”。后期风险可以来自承诺条件未能实现、资源和人口需求变化、后续改造等，但不能依赖先人和 AI 集体忽视明显事实。

### 3. 当前尚未确定的行星条件

- 真实恒星还是虚构恒星，恒星类型及活动。
- 行星质量、半径、地表重力与自转公转。
- 大气压力与成分、是否能够直接呼吸。
- 水、气候、季节、地质与资源分布。
- 本土生命及其与人类的关系。
- 先遣探测证据、登陆流程和轨道设施规模。

**最近的未确认建议：**地表重力约0.7至0.8g，或接近1g。作者尚未选择。不得把飞船中环约0.7g自动当成目标行星重力。

## 十三、与旧大纲的修订关系

旧大纲作为情节工作稿保留，尚未按全部后续设定重写。下一轮修订至少需要处理：

| 旧稿表述或倾向 | 当前需要遵守的方向 |
| --- | --- |
| 人体分化主要从航行开始 | 差异先在太阳系殖民地形成，飞船为既有人群设计；航行中继续变化 |
| 接续者使用有限神经接口，连接加深容易理解为控制加深 | 当前选择持续指导，不采用直接神经运动接管 |
| 守望反对神化但实际利用或依赖崇拜作为主要性格矛盾 | 已确认主动反对神化并减少依赖；不能默认秘密培育或有意利用 |
| 全体原定共同登陆，临近抵达才发现体质障碍 | 出发时即需考虑已知差异；冲突应落在承诺兑现、变化和选择上 |
| 循环农业可以被理解为主要靠作物供粮 | 食物以工业生物制造为主，作物补充 |
| 工程退化单向累积、维修主要延缓衰败 | 允许持续研发、升级、替代和改善；具体资源仍有限 |
| 主线临近抵达才开始减速审查 | 与最终加减速时序协调；二十年只是算例，尚未锁定 |

林衡、叶澄、林遥的人物设计、五部十五章、后发先至、目的地接收与拆船分流结局，继续作为原大纲工作方案。本文不借整理设定之机擅自重写情节，也不把每一项人物命运变成不可修改的世界规则。
